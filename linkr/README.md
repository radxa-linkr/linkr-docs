# 瑞莎灵控

## 产品概述

瑞莎灵控（Radxa Linkr）通过 HDMI 和 USB 连接被控设备，实现远程画面查看与键鼠操作，让用户、开发者和 AI 智能体协同控制真实设备。

支持最高 2K@30Hz HDMI 视频输入、多种网络连接和跨平台免驱控制，适用于无头服务器调试、多设备远程管理及 AI 硬件操控。

## 应用场景

### 无头设备调试

无需为服务器、开发板或工控机临时连接显示器和键鼠，即可查看 / 操作系统。

### 远程运维

通过局域网或 Tailscale 访问异地设备，完成重启、Wake-on-LAN 唤醒、固件设置调整和诊断日志导出。

### 操作系统部署与恢复

上传并挂载 ISO 或 IMG 镜像，为被控设备安装操作系统、加载驱动或执行离线恢复。

### 多设备集中管理

通过 [linkr.now](https://linkr.now/) 发现和区分多台灵控设备，快速进入对应设备的控制台。

### AI 智能体与自动化

通过访问令牌和公开 API 获取屏幕截图、发送键鼠操作，将真实设备接入 AI 智能体、自动化测试、CI/CD 和监控流程。
