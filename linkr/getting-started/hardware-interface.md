## 用户按键

- **短按一次**：设备将在 [linkr.now](https://linkr.now) 上高亮显示，可用于快速定位设备。

- **长按 ≥ 10 秒**：重置设备（将所有配置恢复到出厂默认状态）。

:::warning 重置说明
长按用户按键将重置系统，清除所有本地配置（含网络、账号、Tailscale 绑定等），操作前请确认已备份必要信息。
:::

## USB-C 设备接口

用于连接被控设备的 USB 口传输键盘、鼠标数据或连接 PC 进行固件烧录。

- 传输数据

用于向被控设备传输键盘、鼠标数据，达到远程控制的目的，同时，被控设备也可以通过该接口为灵控供电。

- 烧录固件

当设备出现异常时，可通过 USB-C 设备接口连接 PC，使用烧录工具进行固件烧录。

## HDMI 输入接口

用于连接被控设备的 HDMI 输出口，采集视频信号；最高支持 2K@30Hz 视频输入。

## 视频状态指示灯

板载的视频状态灯用于显示被控设备的视频（HDMI）信号状态，帮助用户判断视频链路是否正常。

| LED 状态 | 说明               |
| -------- | ------------------ |
| 灭       | 无视频信号         |
| 亮       | 有视频信号         |
| 闪烁     | 视频链路异常或错误 |

:::tip 视频状态指示灯

HDMI 指示灯可在 [linkr.now](https://linkr.now) 页面进行控制，可以控制指示灯亮灭。

:::

## 系统状态指示灯

板载的系统状态灯用于显示设备的运行状态，帮助用户判断设备是否正常工作。

| LED 状态 | 说明                       |
| -------- | -------------------------- |
| 蓝色闪烁 | 系统启动中                 |
| 蓝色常亮 | 系统正常运行               |
| 绿色常亮 | 正在被使用中（有活跃连接） |
| 白色闪烁 | 正在升级固件               |
| 白色常亮 | 正在重置系统               |

:::tip 系统状态指示灯

系统状态指示灯可在 [linkr.now](https://linkr.now) 页面进行控制，可以控制指示灯的亮度。

:::


## USB-C 网络接口

用于有线连接管理端 PC 或路由器，支持 USB-C 直连、USB-C 转 RJ45 适配器，提供 10/100 Mbps 以太网连接。
