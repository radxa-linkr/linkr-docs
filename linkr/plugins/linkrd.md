# Linkrd 剪贴板同步

Linkrd 可以在控制端电脑与被控电脑之间双向同步纯文本剪贴板，让你在一端复制、另一端直接粘贴。

使用时需要在灵控上安装 **Linkrd 插件**，并在被控电脑上安装 **Linkrd 程序**。当前仅支持纯文本，不支持图片或文件同步。

## 前置条件

- 灵控固件支持 Linkrd，并准备好对应的 `.apk` 插件包。
- 灵控的 **USB-C 设备接口**已通过数据线连接被控电脑，连接方式参见[硬件接口](../getting-started/hardware-interface.md)。
- 被控电脑运行 Windows x64，或 Linux x64 / ARM64 的 X11、Wayland 桌面会话。
- 控制端使用支持剪贴板读写的浏览器，通过 **HTTPS** 访问灵控，并允许该站点访问剪贴板。

:::tip

控制端是打开灵控 Web 界面的电脑；被控端是通过 HDMI 和 USB 连接灵控的电脑。Linkrd 程序安装在被控端。

浏览器必须信任灵控的 HTTPS 证书。自定义证书的域名或 IP 应与访问地址一致；使用本地 CA 签发的证书时，还需要在控制端信任该 CA 的根证书。仅跳过证书警告不等于浏览器已信任证书。

:::

## 1. 在灵控上安装插件

1. 登录灵控 Web 界面，打开 **插件中心**。
2. 在 **安装插件包** 中上传 Linkrd 的 `.apk` 文件。
3. 上传完成后，检查包名为 **Linkrd**，点击 **确认安装**。
4. 在 **已安装插件** 中开启 Linkrd。

该插件提供包含被控端安装程序的 `Linkrd.img`。安装插件后，还需要按下一节安装被控端程序。

## 2. 在被控电脑上安装程序

### 打开安装磁盘

1. 在灵控 Web 界面进入 **键盘与鼠标 → 快捷粘贴 → 剪贴板同步**，打开 **剪贴板同步** 开关。这会启用 USB ACM 串口通信。
2. 进入 **虚拟设备 → 虚拟磁盘**，找到 `Linkrd.img` 并挂载。
3. 在被控电脑上打开卷标为 **LINKRD** 的磁盘，根据操作系统和处理器选择目录。

| 被控电脑 | 目录 | 安装脚本 |
| --- | --- | --- |
| Windows x64 | `windows-x64` | `install.cmd` |
| Linux x64 | `linux-x64` | `install.sh` |
| Linux ARM64 | `linux-arm64` | `install.sh` |

当前安装磁盘不包含 macOS 版 Linkrd。

### Windows

1. 将 `windows-x64` 整个目录复制到被控电脑的本地磁盘。
2. 双击其中的 `install.cmd`，按窗口提示完成安装。无需以管理员身份运行。

安装后程序会立即在后台启动，并在当前用户下次登录时自动启动。默认安装位置为 `%LOCALAPPDATA%\Programs\linkrd\linkrd.exe`。

### Linux

在被控电脑当前登录的桌面会话中打开终端，进入安装磁盘上的 `linux-x64` 或 `linux-arm64` 目录。先将整个目录复制到主目录下的本地临时目录，再为复制后的安装脚本和程序赋予执行权限并安装：

```bash
linkrd_install_dir=$(mktemp -d -p "$HOME")
cp -R . "$linkrd_install_dir/"
cd "$linkrd_install_dir"
chmod u+x install.sh linkrd
./install.sh
```

执行权限需要在复制后的本地目录中设置，不要在 **LINKRD** 虚拟磁盘中直接执行 `chmod`。

请使用普通桌面用户运行，**不要以 root 身份或通过 `sudo` 运行安装脚本**。脚本会检查串口权限；需要加入 `dialout` 或 `uucp` 组时，会提示输入 `sudo` 密码，并为安装进程刷新组权限。

如果提示需要重新登录，请注销桌面并重新登录，再运行脚本。没有 `sudo` 权限、设备所属组异常或仍无法访问串口时，请联系管理员处理。

安装后程序会立即在后台启动，并在当前用户下次登录时自动启动。默认安装位置为 `~/.local/bin/linkrd`。

:::tip

安装脚本和安装磁盘内的 README 使用英文。Windows、Linux 脚本都会调用程序内置的 `install --autostart` 命令。

安装成功后，可以在灵控的虚拟磁盘设置中卸载 `Linkrd.img`。后续同步使用已安装的程序，不需要一直挂载安装磁盘。

:::

## 3. 开启双向同步

1. 返回 **键盘与鼠标 → 快捷粘贴 → 剪贴板同步**。
2. 确认 **剪贴板同步** 已开启，连接状态变为 **已连接主机**。
3. 打开 **自动双向同步**。如果浏览器请求剪贴板权限，选择允许。
4. 保持灵控页面可见并获得焦点，然后复制新的文字进行同步。

界面中三个开关的用途如下：

| 开关 | 用途 |
| --- | --- |
| Linkrd 插件 | 控制 `Linkrd.img` 在虚拟磁盘列表中的显示，也可在插件中心管理。 |
| 剪贴板同步 | 启用 USB ACM 及与被控电脑的剪贴板通信。 |
| 自动双向同步 | 自动同步控制端和被控端的文字变化，需要浏览器剪贴板权限。 |

自动同步只处理开启后的新变化；连接恢复后不会自动重发断线前的旧文字。切换到其他标签页、最小化浏览器或让页面失去焦点时，自动同步会暂停。返回页面后，如需确保同步，请重新复制所需文字。

## 4. 验证同步

### 控制端到被控端

1. 在控制端复制一段新的文字，例如 `Hello Linkrd 你好`。
2. 返回灵控页面，让页面获得焦点。
3. 在被控电脑的文本编辑器中粘贴，确认内容一致。

### 被控端到控制端

1. 在被控电脑中复制另一段新的文字。
2. 保持灵控页面可见并获得焦点，确认 **主机剪贴板** 中显示该文字。
3. 在控制端的文本编辑器中粘贴，确认内容一致。

## 手动同步

不启用自动同步时，也可以在连接成功后手动操作：

- **发送到被控端**：在 **发送文字** 中输入或粘贴文字，点击 **同步到主机**，再到被控电脑中粘贴。也可以点击 **粘贴本机文字** 读取控制端剪贴板。
- **复制到控制端**：在 **主机剪贴板** 中查看被控端文字，点击 **复制到本机**，再在控制端粘贴。

如果浏览器无法直接访问剪贴板，可以手动在文本框中复制、粘贴。发送内容超过界面显示的字节上限时，需要缩短后重试。**发送空文本会清空被控端的文本剪贴板。**

原有的 **键盘输入** 模式仍可独立使用。

## 管理被控端程序

安装器会配置当前用户的 PATH。请按安装输出提示打开新终端后执行：

| 命令 | 作用 |
| --- | --- |
| `linkrd status` | 查看当前用户的进程是否运行及 PID。 |
| `linkrd --list-ports` | 列出检测到的串口。 |
| `linkrd stop` | 停止当前用户的 Linkrd。 |
| `linkrd start` | 使用已保存的参数在后台启动。 |
| `linkrd autostart status` | 查看登录自动启动的注册状态。 |
| `linkrd autostart disable` | 关闭下次登录时自动启动，不会停止当前进程。 |
| `linkrd autostart enable` | 开启下次登录时自动启动。 |

`linkrd status` 只检查进程，不代表 USB 或剪贴板已经连接；同步状态应以灵控界面中的 **已连接主机** 为准。

如需卸载，请先在被控电脑上执行以下命令，再按需从灵控的插件中心卸载插件：

```bash
linkrd stop
linkrd uninstall
```

卸载程序会移除安装文件和登录自动启动项，保留日志。

## 常见问题

### 找不到 Linkrd.img

确认插件中心中已安装并开启 **Linkrd**，然后刷新虚拟磁盘列表。仅开启 **剪贴板同步** 不会显示安装镜像。

### 一直显示“已开启，等待主机连接”

- 检查灵控的 USB-C 设备接口是否连接到被控电脑，数据线是否支持数据传输。
- 确认被控电脑中已安装程序，执行 `linkrd status` 检查是否运行；未运行时执行 `linkrd start`。
- 执行 `linkrd --list-ports`，确认可以检测到设备串口。
- Linux 用户应在实际登录的 X11 / Wayland 桌面会话中运行程序，并确认当前用户具有串口读写权限。

### Linux 提示 Permission denied

如果在 **LINKRD** 虚拟磁盘中修改执行权限或运行程序失败，请按本页的 Linux 安装步骤，将对应架构的整个目录复制到本地临时目录，在复制后的目录中执行 `chmod u+x install.sh linkrd`，然后运行 `./install.sh`。

如果是串口访问被拒绝，在被控电脑上检查实际设备名和当前会话的用户组，例如：

```bash
ls -l /dev/ttyACM0
id -nG
```

重新运行安装脚本，根据提示授权或注销桌面后重新登录。如果用户组正确仍无法读写设备，请联系管理员检查设备权限或 ACL。

### 被控端文字可以显示，但控制端无法同步

确认 **自动双向同步** 已开启，并检查：

- 访问地址使用 HTTPS，证书受浏览器信任，证书包含当前访问的域名或 IP。
- 浏览器的站点设置中允许访问剪贴板。没有弹出权限窗口时，也请在站点设置中检查权限。
- 灵控标签页可见并获得焦点。
- 在开启自动同步后重新复制一段文字，而不是只使用开启前的剪贴板内容。

仍无法自动同步时，可以先使用 **发送文字 → 同步到主机** 验证手动发送。

### 手动发送超时或连接中断

刷新连接状态，并在两端检查当前剪贴板内容。请求超时不代表文字一定未写入；确认内容后再决定是否重新发送。
