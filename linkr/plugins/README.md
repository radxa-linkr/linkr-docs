# 插件

通过插件扩展瑞莎灵控的功能。

**目前仅支持官方发布的插件，暂不支持自定义插件。** 请从下方的官方插件下载页面获取安装包。

插件安装在灵控设备上，通过 Web 界面的 **插件中心** 管理。部分插件还需要额外配置或安装被控端程序，具体要求请参见对应插件的使用指南。

## 使用前提

- 灵控固件支持 **插件中心**。
- 控制端电脑可以访问灵控 Web 界面，并已登录。
- 灵控具有足够的可用存储空间。

## 下载插件

1. 在控制端电脑上打开 [官方插件下载页面](https://github.com/radxa-linkr/plugins/releases/latest)。
2. 展开发布页的 **Assets**，下载所需插件的 `.apk` 文件。例如，Linkrd 插件的文件名以 `Linkrd-` 开头。
3. 将文件保存到控制端电脑，供下一步上传。无需解压，也无需在电脑上运行该文件。

请下载发布页提供的插件 `.apk` 文件；**Source code** 源码压缩包不能用于插件中心安装。这里的 `.apk` 是灵控插件软件包，不能使用普通 Android 应用安装包替代。

## 安装插件

1. 登录灵控 Web 界面，打开侧边栏的 **插件中心**。
2. 选择 **安装插件包**，点击上传区域选择已下载的 `.apk` 文件，也可以将文件拖入该区域。单个文件不能超过界面标注的 **100 MB**。
3. 等待上传完成，核对页面显示的插件包名称、版本、架构、安装大小和描述。
4. 点击 **确认安装**，等待安装成功。上传完成仅表示文件已传到灵控，仍需确认安装。
5. 安装成功后，页面会切换到 **已安装插件**。确认列表中出现对应插件及版本，再按插件要求完成配置并启用。

如果上传了错误的插件包，或暂时不想安装，点击 **放弃** 删除待安装包。此操作不会卸载已安装的插件。

## 启用与停用插件

在 **已安装插件** 中找到对应插件，使用其开关控制启用状态：

- **开启**：启动插件服务，并启用开机自动启动。
- **关闭**：停止插件服务，并关闭开机自动启动；插件仍保留在已安装列表中。

部分插件提供专用配置面板，需要先完成配置才能启用。例如，EasyTier 需要先配置网络。请按界面提示和对应插件的使用指南操作。

## 卸载插件

1. 打开 **插件中心 → 已安装插件**。
2. 找到需要移除的插件，点击 **卸载**。
3. 在 **卸载插件** 确认窗口中核对插件名称，再次点击 **卸载**。
4. 等待出现卸载成功提示，确认该插件已从列表中移除。

卸载时会自动停止插件服务并关闭其开机自动启动，无需先手动关闭开关。卸载不代表所有插件配置都会被清除；例如，EasyTier 需要先执行 **退出网络** 才会删除网络配置。

如果当前通过待卸载的网络插件远程访问灵控，请先切换到其他可用的访问方式，以免卸载后连接中断。

## 常见问题

### 找不到插件中心

检查当前固件是否支持插件中心，必要时按 [固件更新](../getting-started/firmware-update.md) 文档升级。

### 上传后没有出现在已安装插件中

检查 **安装插件包** 页面是否仍在等待确认。上传完成后需要点击 **确认安装**，只有安装成功才会加入已安装列表。

### 提示插件包无效、不受支持或安装失败

确认文件来自官方插件下载页面，是完整的 `.apk` 插件包，并适用于当前固件。按界面错误提示处理，必要时重新下载后上传，并检查灵控的可用存储空间。
