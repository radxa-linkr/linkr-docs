# 使用 OBS 捕获 Linkr 视频

通过 OBS Studio 的 **浏览器（Browser）** 源加载灵控设备的管理页面，可以捕获被控设备的远程画面，并将其加入 OBS 场景。

## 使用前提

- 被控设备已通过 HDMI 连接灵控，且管理界面能正常显示视频。
- 运行 OBS 的电脑可以通过网络访问灵控。
- 已安装 [OBS Studio](https://obsproject.com/)，且来源列表中包含 **浏览器（Browser）**。

## 获取设备地址

1. 在普通浏览器中打开 [linkr.now](https://linkr.now/)，找到并进入需要捕获画面的灵控设备。
2. 复制设备管理页面地址栏中的地址，保留实际使用的协议、IP 地址或域名及端口。例如，设备通过 HTTP 访问时，地址可能为 `http://192.168.1.100/`，请替换为你的设备地址。

OBS 浏览器源的 URL 应填写设备自身的管理地址。`https://linkr.now/` 是设备发现入口，不是设备的视频页面。

## 添加浏览器源

1. 打开 OBS，创建或选择一个场景。
2. 在 **来源（Sources）** 面板点击 **+ → 浏览器（Browser）**，创建一个新源，例如命名为 `Linkr`。
3. 取消勾选 **本地文件（Local file）**，将 **URL** 设置为上一步获取的设备管理地址。
4. 设置 **宽度（Width）** 和 **高度（Height）**，例如 `1920 × 1080`。这两个参数决定网页的渲染尺寸，不会修改被控设备的 HDMI 输出分辨率。
5. 如需指定渲染帧率，勾选 **使用自定义帧率（Use custom frame rate）**，按实际视频帧率设置 FPS，例如 `30`。提高此值不会提高灵控视频本身的帧率。
6. 点击 **确定** 保存。

## 登录并整理画面

1. 右键点击刚创建的浏览器源，选择 **交互（Interact）**。
2. 在交互窗口中输入灵控的用户名和密码，按提示完成登录；已启用双重验证时，还需输入验证码。
3. 确认交互窗口和 OBS 预览中都出现持续更新的被控设备画面，然后关闭交互窗口。
4. 如需只保留视频区域，右键点击来源，选择 **变换（Transform）→ 编辑变换（Edit Transform）**，调整上、下、左、右的裁剪值，去掉侧边栏和底部工具栏。
5. 调整来源在画布上的位置和大小，保持视频原有的宽高比。

:::tip 登录与连接

OBS 的浏览器源使用独立的浏览器会话，需要在 **交互** 窗口中完成登录。当前固件登录新的会话会替换旧会话，捕获期间请避免在其他浏览器中重新登录同一台灵控，以免中断 OBS 的连接。

如需切换场景后保持连接，可在浏览器源属性中保持 **不可见时关闭源（Shutdown source when not visible）** 和 **场景变为活动状态时刷新浏览器（Refresh browser source when scene becomes active）** 关闭。

:::

## 验证捕获画面

1. 在被控设备上切换窗口或移动鼠标，确认 OBS 预览中的画面同步更新。
2. 检查视频区域是否完整、宽高比是否正确，以及是否存在黑屏或意外裁剪。
3. 确认关闭 **交互** 窗口后，OBS 预览中的视频仍持续更新，即完成捕获配置。

## 常见问题

- **来源列表没有“浏览器”**：安装包含浏览器源组件的 OBS 官方发行包。Linux 上的部分第三方软件包可能未包含该组件。
- **只显示登录页面**：右键来源选择 **交互**，在 OBS 内完成登录。
- **HTTPS 页面无法加载**：检查设备证书是否有效，并确保 OBS 运行环境信任该证书。普通浏览器中已接受的证书提示不代表 OBS 已信任该证书。
- **页面已连接但视频黑屏**：先确认被控设备有 HDMI 输出，再在交互窗口中尝试将灵控的 **视频模式** 切换为 **MJPEG**。调整后仍无画面时，检查网络连接，并在浏览器源属性中点击 **刷新当前页面缓存（Refresh cache of current page）** 后重新连接。
- **切换分辨率后画面被裁剪或有黑边**：重新调整浏览器源尺寸、裁剪区域及 OBS 画布，保持视频宽高比。

OBS 参数说明参见官方 [浏览器源文档](https://obsproject.com/kb/browser-source) 和 [快速入门指南](https://obsproject.com/kb/quick-start-guide)。
