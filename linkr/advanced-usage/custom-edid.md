# 自定义 EDID

EDID（Extended Display Identification Data，扩展显示标识数据）是由 VESA 制定的标准数据格式，包含显示设备的制造商、支持的分辨率、刷新率等信息。被控设备通过 HDMI 读取灵控提供的 EDID，并据此选择合适的视频输出参数。

灵控的预设 EDID 可以满足大多数使用场景。仅当被控设备无法提供所需的分辨率或刷新率，或预设 EDID 与被控设备不兼容时，才建议配置自定义 EDID。

:::warning

无效或超出灵控采集能力的 EDID 可能导致无画面、画面不稳定或无法选择目标显示模式。配置前请记录当前使用的预设 EDID，以便恢复。

:::

## 限制

选择或生成 EDID 时，请遵循以下限制：

- 视频采集最高支持 **2K @ 30 FPS**；EDID 中声明的最大分辨率、首选分辨率和刷新率均不得超过此规格。
- 不支持隔行扫描，请只使用逐行扫描模式。
- 最多支持 **2 个 EDID block**，即 128 字节（1 block）或 256 字节（2 blocks）。
- 灵控不会从 HDMI 采集音频，因此 EDID 是否声明音频能力不会影响音频采集。如需采集被控设备的音频，请使用[虚拟设备](../web#虚拟设备)下的 **虚拟声卡** 功能。

## 准备 EDID 数据

你可以使用已知可用的显示器 EDID，也可以从 [linuxhw/EDID](https://github.com/linuxhw/EDID) 数据库中查找符合上述限制的 EDID。

以 linuxhw/EDID 数据库为例：

1. 进入 `Digital` 目录，按制造商、型号和分辨率查找合适的显示器。
2. 点击该显示器对应的 **ID**，打开 EDID 详情页。

![在 linuxhw/EDID 数据库中选择显示器 ID](/img/linkr/custom-edid-database.webp)

3. 找到 `edid-decode (hex)`，复制其下方的十六进制字节。只复制 EDID 数据，不要包含标题、行号、分隔线或后面的解析结果。

![复制 edid-decode (hex) 下方的 EDID 数据](/img/linkr/custom-edid-hex.webp)

:::tip

详情页中的 `Block 0` 表示第一个 128 字节 block。如果页面还包含 `Block 1`，则该 EDID 为 256 字节。请勿使用包含 `Block 2` 或更多 block 的 EDID。

:::

## 配置步骤

1. 打开灵控管理 Web 界面并登录。
2. 在工具栏中进入 **画面设置**。
3. 打开 **分辨率/帧率**（EDID）选项，选择 **自定义**。
4. 将准备好的十六进制 EDID 数据粘贴到输入框中。
5. 点击 **保存**，等待被控设备重新识别显示信息。

保存后，HDMI 画面可能会短暂中断。部分操作系统不会立即重新读取 EDID，此时需要重新插拔被控设备的 HDMI 连接，或重启被控设备。

## 验证配置

画面恢复后，在被控设备的显示设置中检查：

- 是否可以选择 EDID 中声明的目标分辨率和刷新率。
- 灵控 Web 画面是否稳定、比例是否正确。
- 重新连接 HDMI 或重启被控设备后，配置是否仍然生效。

## 恢复预设 EDID

如果保存后无画面或显示异常：

1. 返回灵控 Web 界面的 **画面设置**。
2. 打开 **分辨率/帧率**（EDID）下拉列表，选择灵控提供的任一预设分辨率和帧率。

选择后即可恢复预设 EDID，无需清空自定义 EDID 输入框。

## 常见问题

### 保存后没有画面

- 确认 EDID 仅包含 1 或 2 个 block。
- 确认首选模式未超过 2K @ 30 FPS，且不是隔行扫描模式。
- 检查复制的内容是否只有完整的十六进制字节，没有混入行号或解析文本。
- 从 **分辨率/帧率**（EDID）下拉列表中选择灵控提供的预设分辨率和帧率。

### 被控设备中没有出现目标分辨率

- 确认目标模式确实包含在 EDID 的详细时序或标准时序中。
- 重新插拔 HDMI，强制被控设备重新读取 EDID。
- 若操作系统缓存了显示器信息，请重启被控设备后再检查。

### 可以使用带音频信息的 EDID 吗

可以，但灵控不会从 HDMI 采集音频，EDID 中的音频能力声明不会让远程画面获得音频。如需采集被控设备的音频，请使用[虚拟设备](../web#虚拟设备)下的 **虚拟声卡** 功能，将音频传输到浏览器播放。
