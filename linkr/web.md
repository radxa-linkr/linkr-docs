# linkr.now 介绍

[linkr.now](https://linkr.now/) 是基于浏览器的设备发现与管理平台，可发现并统一管理局域网内的多台灵控设备，无需安装客户端。

主要功能包括：

- 查看被控设备画面并进行远程操作

- 使用文本粘贴、截图、录屏和自定义快捷键等辅助功能

- 配置以太网、USB 网卡、Wi-Fi 和 Wi-Fi 热点

- 管理虚拟磁盘及挂载 ISO、IMG 镜像

- 升级固件以及管理用户、设备名称和系统重置等设置

## 使用指南

访问 [linkr.now](https://linkr.now/) 会出现简单的使用指南：

1. 连接设备：提示灵控设备的硬件连接。

2. 访问与扫描：授权本地网络访问权限和扫描局域网下的灵控设备。

3. 选择设备：选择需要控制的灵控设备。

4. 设备管理界面：被控设备的管理/控制界面。

前 3 个步骤网站会自动引导用户进行操作，教程主要介绍设备管理界面的功能。

## 设备管理界面

设备管理界面主要被划分为 3 个区域：

- 侧边区域（图中划分的红色区域）：主要功能区，包含网络设置、画面设置、键盘与鼠标、虚拟设备、系统设置、高级设置等功能。

- 底部区域（图中划分的绿色区域）：状态栏和工具栏，显示连接信息和全屏、截屏、录频以及屏幕键盘等常用工具。

- 中央区域（图中划分的蓝色区域）：被控设备的系统画面。

### 主要功能区（侧边）

#### 常用工具

可自定义聚合区，可以将一些常用工具添加到这里，避免频繁切换和查找设置。

#### 网络设置

用于查看网络状态，并配置灵控的网络连接方式。

<div style={{textAlign: 'center'}}>
   <img src="/img/linkr/linkr-network.webp" style={{width: '100%', maxWidth: '1200px'}} />
</div>

1. 以太网

通过有线网络将灵控接入局域网。支持 DHCP 自动获取网络参数，也可手动设置 IPv4 地址、子网掩码、网关和 DNS。

2. USB 网卡

通过 USB-C 在灵控与主机之间建立直连网络，适用于首次配置和本地调试。支持自定义 USB 网卡网段。

3. Wi-Fi

将灵控接入无线局域网。支持扫描或手动添加网络，并可配置 DHCP 或手动 IP。

4. Wi-Fi 热点

将灵控作为无线接入点，供主机直接连接，适用于无可用局域网或临时直连场景。支持设置热点名称、安全模式、密码、隐藏热点和热点网段。

:::tip 提示

- 手动设置网段时，请使用 CIDR 格式，例如 `192.168.99.0/24`。

- 以太网、USB 网卡、Wi-Fi 和 Wi-Fi 热点应使用不同网段，以免发生网络冲突。

- 修改 IP 地址或网段后，当前连接可能中断，请使用新的 IP 地址重新访问管理界面。

- 使用 WPA2 模式创建 Wi-Fi 热点时，密码长度不得少于 8 个字符。

:::

#### 画面设置

用于调整远程画面的显示方式和视频传输参数。

<div style={{textAlign: 'center'}}>
   <img src="/img/linkr/linkr-display.webp" style={{width: '100%', maxWidth: '1200px'}} />
</div>

1. 全屏

将远程控制画面切换为浏览器全屏显示，适合长时间操作或沉浸式使用。

2. 缩放模式

设置画面在浏览器窗口中的显示方式。

   - 自适应：按窗口大小缩放，完整显示画面。

   - 常规：按原始比例显示画面。

3. 分辨率与帧率（EDID）

设置被控设备通过 HDMI 识别到的显示分辨率和刷新率。适用于解决画面输出异常，或指定特定的分辨率与帧率。

4. 图像质量

调整远程画面的清晰度与传输流畅度。画质越高，对网络带宽的要求越高。

5. 视频模式

设置远程画面使用的视频编码格式。

   - H.264：编码效率高、带宽占用较低，推荐日常使用。

   - MJPEG：兼容性较好，适用于部分无法正常使用 H.264 的环境。

:::tip 提示

- 修改分辨率或帧率后，被控设备的画面可能短暂中断。

- 网络状况较差时，可降低图像质量以提升画面流畅度。

- 建议优先使用 H.264；出现兼容性问题时，可切换为 MJPEG。

:::

#### 键盘与鼠标

用于配置远程输入方式，提高键盘和鼠标操作效率。

<div style={{textAlign: 'center'}}>
   <img src="/img/linkr/linkr-input.webp" style={{width: '100%', maxWidth: '1200px'}} />
</div>

1. 屏幕键盘

打开或关闭虚拟键盘，适用于触控设备或没有实体键盘的场景。

2. 快捷粘贴

将文本快速输入被控设备，并支持查看、复用和清空粘贴记录。适合输入命令、路径等较长文本。

3. 快捷键输入

添加并发送自定义组合键，适合执行常用系统操作。

4. 鼠标设置

支持启用或关闭鼠标输入、显示本地鼠标，以及配置鼠标模式、灵敏度、滚轮方向和滚动速度。

   - 绝对模式：浏览器指针位置与被控设备指针位置保持一致，适合桌面操作。

   - 相对模式：根据鼠标移动量控制被控设备指针，适合 BIOS、游戏或部分特殊系统。

:::tip 提示

5. 相对模式下可调整鼠标灵敏度，以改善操作手感。

6. 开启“防止休眠”后，灵控会定期发送鼠标活动，避免被控设备因长时间无操作进入休眠。

:::


#### 虚拟设备

用于管理虚拟磁盘，将系统镜像或维护镜像挂载到被控设备。

<div style={{textAlign: 'center'}}>
   <img src="/img/linkr/linkr-virtul-disk.webp" style={{width: '100%', maxWidth: '1200px'}} />
</div>

1. 虚拟磁盘

支持上传、挂载、卸载和删除 ISO、IMG 镜像，并可查看存储空间和上传进度。

挂载镜像后，被控设备会将其识别为 USB 存储设备，可用于安装系统、加载驱动或进行离线维护。

:::tip 提示

- 仅支持 `.iso` 和 `.img` 格式的镜像文件。

- 上传前请确认灵控具有足够的可用存储空间。

:::

2. 虚拟声卡

在被控设备上模拟 USB 声卡，将被控设备的音频传输到浏览器播放。

#### 系统设置

用于管理灵控的账户、设备信息和系统维护功能。

<div style={{textAlign: 'center'}}>
   <img src="/img/linkr/linkr-setting.webp" style={{width: '100%', maxWidth: '1200px'}} />
</div>

1. 用户信息

修改登录用户名和密码，用于管理访问身份与登录安全。

2. 访问令牌

创建和删除 API Key，供脚本、AI 智能体或自动化工具访问灵控接口。

3. 安全

启用或关闭双重验证（2FA）。

启用后，登录时除用户名和密码外，还需输入身份验证器生成的一次性验证码，进一步提升账户安全性。

:::tip 提示

- 启用 2FA 前，请先在身份验证器应用中完成绑定，并确认验证码可正常使用。

- 请妥善保存恢复信息，避免更换或丢失验证设备后无法登录。

:::

4. LED 控制

调整灵控状态指示灯的显示状态。

   - HDMI 指示灯：开启或关闭 HDMI 视频状态指示灯。

   - 系统指示灯：调整系统状态指示灯的亮度。

5. 语言

切换管理界面的显示语言，支持简体中文和 English。

6. 设备名称

修改设备的显示名称，便于在局域网和设备列表中识别不同的灵控设备。

7. 系统更新

上传本地升级包，查看更新进度并完成固件升级。

8. 重置设备

将灵控恢复至默认状态，并清除当前系统配置。

9. 重启设备

重新启动灵控设备。

#### 高级设置

用于配置灵控的远程访问和设备唤醒功能。

<div style={{textAlign: 'center'}}>
   <img src="/img/linkr/linkr-advance.webp" style={{width: '100%', maxWidth: '1200px'}} />
</div>

1. Tailscale

将灵控接入 Tailscale 网络，实现跨局域网安全访问。适用于异地运维或无法通过本地网络直接访问灵控的场景。

2. MAC 设备唤醒

通过网络向被控设备发送唤醒指令，实现远程开机。适用于支持 Wake-on-LAN（WoL）的设备。

:::tip 提示

- 使用 Tailscale 前，请确保灵控已通过以太网或 Wi-Fi 连接互联网。

- 使用 MAC 设备唤醒前，需要在被控设备的 BIOS 和操作系统中启用 Wake-on-LAN。

- 请确保填写的 MAC 地址属于被控设备用于网络唤醒的网卡。

- 设备断电或硬件不支持 Wake-on-LAN 时，无法通过该功能唤醒。

:::
